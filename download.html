Before you run Setup

This build is unsigned, so Windows may show an “Unknown publisher” or reputation prompt. Check the SHA-256 checksum above against your downloaded file. DMC Player does not install itself silently.

Installation

Here is how to get started.

  1. 1

    Run the installer

    Setup installs for your Windows account and includes VLC and .NET. If needed, it offers Microsoft's WebView2 Runtime for service websites.

  2. 2

    Open your media

    Drop in a file, paste a direct stream, choose Live TV or open a web service from the File menu.

  3. 3

    Go small

    Set your game to borderless windowed mode. Press Ctrl + Alt + O, move the picture and lock clicks with Ctrl + Alt + L.

Updates

The player lets you know about new versions.

From version 2.6, DMC Player checks the public release information at startup and every six hours while open and shows an update button when a newer version is available. You can also check from the Help menu.

You choose Download update, then Install update after the installer has been checked against its published size and SHA-256. Nothing downloads or installs silently while you play. Close the older running copy before installing an update; your manually selected queue, channel lists, favourites and service sign-ins are retained.

Older builds can update by downloading the latest installer from this page. Portable users should extract the full new folder.
