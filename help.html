GETTING STARTED

Your first few minutes.

  1. 1

    Install and open

    Download Setup for a normal installation, or extract the complete portable ZIP. Keep all the player files together.

    Downloads ↗
  2. 2

    Choose something

    Use File → Open file, Open stream or Live TV. YouTube and streaming services open their own websites inside the player.

    Live TV guide ↗
  3. 3

    Make room

    Use your game in borderless windowed mode. Press Ctrl + Alt + O, drag the mini player and stretch it to fit.

    Player controls ↗

KEYBOARD SHORTCUTS

Worth remembering.

Ctrl + Alt + O
Mini / restore, even while the game has focus
Ctrl + Alt + L
Lock / unlock mouse click-through
Ctrl + Alt + Space
Request play / pause from another app
F11
Toggle DMC Player fullscreen
Esc
Leave fullscreen or mini mode
Ctrl + O
Open a local file
Ctrl + L
Open a direct stream
F1
Open the in-app help

For files and direct streams: Space plays/pauses, M mutes, and Left/Right skip ten seconds when the source is seekable. Provider websites may handle keys differently.
